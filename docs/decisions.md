# Рабочие решения

Все пункты ниже предложены для реализации и требуют продуктового подтверждения перед публичным запуском.

- Dev-справочник: баскетбол, футбол, волейбол, бег; география — явно тестовый район. Реальный кластер и 1–2 приоритетных спорта не выбраны.
- Возраст: 18–100, игроки сверх организатора: 1–5. Значения конфигурируются.
- TTL пустой активности — 48 часов; напоминание — за 60 минут; запрос результата — через 120 минут после старта.
- Активность без принятых участников после старта истекает; с принятыми — технически завершается. Только положительное подтверждение участника делает встречу успешной.
- Для North Star достаточно одного допустимого положительного подтверждения. Противоречащие ответы помечаются спорными.
- Рейтинг доступен только тому, кто сам подтвердил состоявшуюся встречу.
- После принятия нельзя менять спорт, район, место и время. Число мест не уменьшается ниже принятого состава.
- Контакт остаётся доступен принятой паре после завершения, пока нет отмены или блокировки.
- При блокировке будущие pending/accepted связи пары закрываются; прошедший состав и аналитическая история не переписываются.
- Сессия — подписанный bearer token на 24 часа в памяти вкладки. Это исключает CSRF для cookie, но требует строгого CSP на production reverse proxy.

Открытые вопросы: политика несовершеннолетних, реальные район/виды спорта, определение достаточного подтверждения встречи, поведение accepted-участника при отказе, сроки хранения PII и жалоб.
