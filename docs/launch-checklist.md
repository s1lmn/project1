# Launch checklist

- [ ] Партнёры выбрали один реальный кластер и 1–2 спорта.
- [ ] Проведены и разобраны 20 интервью; scope подтверждён обоими партнёрами.
- [ ] Новый токен бота хранится в secret storage; Mini App настроен на публичный HTTPS URL.
- [ ] Staging: миграции с чистой PostgreSQL, backup/restore и rollback проверены.
- [ ] Telegram E2E пройден на iOS/Android/Desktop, включая уведомления и deep links.
- [ ] Security: dev auth выключен; origins точные; secrets scan; internal endpoint закрыт.
- [ ] Alpha 20–30 человек завершена; P0=0, P1=0.
- [ ] Собраны 10–20 реальных активностей на ближайшие дни без фейковых пользователей.
- [ ] Таблица 10–20 каналов: название, размер, контакт, разрешение, источник, результат.
- [ ] Есть ответственный за ежедневный контроль пустой ленты и активностей без откликов.
- [ ] Первые 50–100 пользователей привлекаются только после согласования публикаций.
- [ ] Через ~100 пользователей заполнен разбор: demand, liquidity, matches, retention, рабочие спорт/район, bottleneck; решение `iterate / pivot / expand` и 1–3 гипотезы.
