# Альфа-тест

Состав: 5–10 знакомых для ошибок и 10–20 незнакомых целевых пользователей. Каждый проходит без подсказок: Telegram-вход, onboarding, создание, фильтры, отклик, accept/reject, защищённый контакт, уведомление, подтверждение и рейтинг.

Таблица наблюдения: участник/сегмент; устройство и Telegram; шаг; ожидание; фактическое действие; проблема; severity; видео/скрин с согласия; ответственный; статус повторной проверки.

Severity: P0 — продукт нельзя использовать; P1 — сломан critical flow; P2 — работает плохо; P3 — косметика. Переход в beta только при P0=0 и P1=0 по реальным результатам, а не по автоматическим тестам.
