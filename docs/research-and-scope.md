# Материалы M0 и запуска

## Решение о стартовом кластере

Заполнить партнёрам: название и точные границы зоны; оценка целевой аудитории; 10–20 доступных локальных каналов; время перемещения внутри зоны; 1–2 приоритетных спорта; ответственный; дата пересмотра решения.

## CustDev — 20 интервью

Для каждого интервью фиксировать дату, сегмент, спорт/частоту, последний реальный случай «не с кем», текущий способ поиска, допустимое расстояние, горизонт планирования, опыт встречи с незнакомыми, данные для доверия и дословный ключевой сигнал. Не спрашивать «пользовались бы?» и не подменять результат гипотезой.

## Scope approval

Оба партнёра подтверждают список MVP из исходного промта, исключения и открытые решения в `decisions.md`. Любое расширение получает проблему, ожидаемый эффект на core loop, стоимость и явно убираемую/переносимую задачу.

## Карта экранов

Вход → onboarding → лента → детали → отклик → статус → контакт → результат → рейтинг. Параллельные ветки: создание → мои/организую → список откликов → решение; профиль → редактирование; чужой профиль → report/block. Реализованный UI — инженерное предложение, не согласованная Figma.
